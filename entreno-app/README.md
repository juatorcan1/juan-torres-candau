# El entreno de Juan

El gimnasio de Juan, solo suyo: la misma app que «Juan vs Ignacio» (`gym-app/`), sin el duelo y con los datos
aparte. Nadie más que Juan la abre ni ve lo que apunta.

Web: https://juatorcan1.github.io/juan-torres-candau/entreno/ (entra con el usuario de Juan de siempre).

Abajo hay cinco botones: **Hoy**, **Entrenador**, **＋ Apuntar**, **Dietista** y **Progreso** (resumen, historial
y récords). Todo lo demás funciona como en `gym-app/README.md`.

El 22/11/2026 se trajo todo lo de Juan de «Juan vs Ignacio» (entrenos, planes, perfil, chats, copas, comidas y
las versiones anteriores del historial): migración `20261122230023_entreno_traer_lo_de_juan.sql`. En `gym_docs` no se
cambió ni se borró nada.
